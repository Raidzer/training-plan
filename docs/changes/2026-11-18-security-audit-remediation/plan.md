# Устранение замечаний аудита безопасности

Статус: в работе
Ветка: `fix/security-audit-findings`

## Области

- Импорт XLSX и отображение сохранённого текста.
- Вебхук Алисы.
- Авторизация чтения шаблонов.
- Сброс пароля и отзыв JWT-сессий.
- [Импорт и экспорт дневника и плана](../../spec/import-export.md).

## Цель и границы

Закрыть шесть замечаний статического аудита релизного снимка `928c7228` без
изменения формата XLSX и без обновления зависимостей. Внешняя настройка
доверенного входа Алисы остаётся частью развёртывания и не может быть проверена
из репозитория.

## Критерии приёмки

- [x] Импортируемый текст не исполняется как произвольный HTML.
- [x] До ExcelJS отклоняются повреждённые и чрезмерно распаковываемые XLSX.
- [x] Вебхук Алисы требует секрет доверенного входа, ID навыка и подавляет replay.
- [x] Чтение шаблонов ограничено глобальными и собственными шаблонами пользователя.
- [x] Запросы сброса пароля сериализованы и ограничены cooldown.
- [x] Смена пароля отзывает ранее выданные JWT-сессии.
- [ ] Применить миграцию и выполнить PostgreSQL integration-тесты в окружении с БД.
- [ ] Провести ручную проверку доверенного входа Алисы после настройки адаптера.

## Технические решения

- Сохранённое форматирование Excel отображается через ограниченный React-рендерер,
  а не через `dangerouslySetInnerHTML`.
- ZIP проверяется по центральному каталогу и дополнительно распаковывается
  потоковой функцией zlib с ограничением результата до вызова ExcelJS.
- Для Alice webhook внешний запрос не считается доверенным без заголовка,
  установленного внутренним адаптером; сверка `skill_id` используется дополнительно.
- Версия пароля хранится в `users.password_changed_at` и сравнивается в JWT/auth.
