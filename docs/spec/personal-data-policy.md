# Обработка персональных данных при регистрации

На страницах `/privacy` и `/personal-data-consent` без входа доступны политика обработки персональных данных и отдельный текст согласия. Политика описывает оператора, обращение по вопросам данных, цели обработки и работу личного дневника. Участник сам отправляет тренеру сформированный отчёт или выгрузку.

## Регистрация по приглашению

- Форма показывает отдельный чекбокс согласия перед кнопкой «Создать аккаунт». По умолчанию отметки нет. Ссылки на документы открываются в новой вкладке. При отправке формы без отметки появляется ошибка рядом с чекбоксом.
- Регистрация передаёт логическое подтверждение и версию отдельного текста согласия. Для корректной формы с отсутствующим или ложным подтверждением либо с другой версией `POST /api/register` возвращает `400` с кодом `consent_required`. В этом случае аккаунт не создаётся и приглашение остаётся доступным.
- Для новой учётной записи версия согласия и дата по серверным часам сохраняются при создании аккаунта в той же транзакции, что и погашение приглашения. Для учётных записей, созданных до введения согласия, новые поля остаются `NULL`. Подтверждение относится к регистрации, работе аккаунта и личного дневника.
